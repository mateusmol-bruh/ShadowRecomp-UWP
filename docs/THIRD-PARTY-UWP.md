# Avisos de terceiros

O [código do ShadowRecomp e deste port](../LICENSE) está sob a GNU GPL v3. Na página de cada versão em [Releases](https://github.com/mateusmol-bruh/ShadowRecomp-UWP/releases), a tag identifica o código que corresponde ao pacote APPX. Consulte o [guia de compilação](BUILDING-UWP.md) para gerar e assinar sua própria versão.

O arquivo `Third-Party-Notices.zip`, disponível junto do APPX, reúne as licenças fornecidas pelos projetos de base e pelas dependências. Os arquivos da Microsoft conservam suas licenças próprias.
